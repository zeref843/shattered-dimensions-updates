## Three things to know first

- **You bring the game.** Shattered Dimensions contains no game data. Its setup builds the game on your PC from a decrypted dump of your own cartridge of The Legend of Zelda: A Link Between Worlds (US release).
- **F10 opens the settings window** at any time in the game: controls, graphics, the minimap and HUD, and texture packs.
- **Your saves are safe.** They live in your own user folder, are written so that a crash cannot corrupt them, and are kept through every update.

> Shattered Dimensions is an unofficial project, not affiliated with Nintendo. This handbook describes the current version only; features that are planned are marked as planned.
