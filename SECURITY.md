# Security

If you find a security problem in Shattered Dimensions or in its updates, please report it privately so we can fix it before it is public: on this repository, open the **Security** tab and choose **Report a vulnerability**. Please do not open a public issue for it.

Tell us the version, what you found and how to reproduce it. Do not include game files, keys, or anyone's personal information.

Only the latest version receives security fixes. Every official download and update is signed; a copy from anywhere other than this repository's Releases page or shattereddimensions.com is not ours.
